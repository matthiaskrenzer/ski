# ASCII Ski

Standalone-PWA: ASCII-Ski im C64-Look. Widmung: Für Udo May-Jung.

Technik: Vanilla HTML/CSS/JavaScript, PWA.

## Lokal starten

```bash
npm run dev
```

## Produktions-Build

```bash
npm run build
```

Ausgabe: `dist/` (wird nicht versioniert)

Vorschau des Builds:

```bash
npm run preview
```

## Hosting

Ziel ist Firebase Hosting. Deploybar ist der Inhalt von `dist/`.
